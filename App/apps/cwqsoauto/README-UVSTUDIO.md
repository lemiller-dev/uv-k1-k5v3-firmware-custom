# CW QSO Auto — UV-K5 V3

## 🇫🇷 Français

**CW QSO Auto** permet d'envoyer automatiquement des messages en morse (CW) depuis un Quansheng UV-K5 V3 équipé du firmware F4HWN.

16 messages personnalisables, répétition automatique et manipulation STRAIGHT / IAMB A / IAMB B.

# 👉 [🎯 OUVRIR L'ÉDITEUR CW QSO AUTO](https://www.electrosoft.fr/editor.html)

**⚠️ Important :** l'application fournie dans UVStudio contient des messages d'exemple. Vous devez les personnaliser, notamment votre indicatif.

1. Ouvrez l'éditeur dans votre navigateur.
2. Personnalisez vos 16 messages.
3. Téléchargez le fichier `.app` généré.
4. Installez-le avec UVStudio.

**Aucune compilation nécessaire !**

---

## 🇬🇧 English

**CW QSO Auto** sends automatic Morse code messages from a Quansheng UV-K5 V3 running F4HWN firmware.

16 customizable messages, automatic repetition, and STRAIGHT / IAMB A / IAMB B keying.

# 👉 [🎯 OPEN THE CW QSO AUTO EDITOR](https://www.electrosoft.fr/editor.html)

**⚠️ Important:** the UVStudio application contains example messages. Customize them before use, especially your callsign.

1. Open the editor in your browser.
2. Customize your 16 messages.
3. Download the generated `.app` file.
4. Install it using UVStudio.

**No compilation required!**
